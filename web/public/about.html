About Flare AI

Flare AI is a school-focused AI chat assistant by Flare Corporation for students aged 10 and up. It explains topics step by step, reads text from files and images, searches the web with cited sources, listens to voice input and runs Python code in the browser. The interface is available in Azerbaijani, Russian and English.
