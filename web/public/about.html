Necə işləyir

1. Sual verin

2. Rejimi seçin
Sürətli rejim qısa cavab verir. DeepThink mürəkkəb sualları daha dərin təhlil edir. Feynman rejimi mövzunu sizin izah etməyinizə əsaslanır.
3. Yoxlayın
Veb axtarış açıq olanda mənbələr göstərilir. Vacib məlumatı dərslik və ya etibarlı mənbə ilə yoxlayın.

About Flare AI

Flare AI is a school-focused AI chat assistant by Flare Corporation for students aged 10 and up. It explains topics step by step, reads text from files and images, searches the web with cited sources, listens to voice input and runs Python code in the browser. The interface is available in Azerbaijani, English and Turkish.
